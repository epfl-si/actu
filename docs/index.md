# Documentation

This documentation follows the [Diátaxis](https://diataxis.fr/) framework.

Diátaxis helps us organize documentation around the **reader's needs**, rather than around the structure of the project. It defines four types of documentation:

* **Explanation** — understanding concepts, decisions, and architecture
* **How-to guides** — completing a specific task
* **Reference** — looking up precise technical information
* **Tutorials** — learning through a guided experience

When adding documentation, consider **what the reader is trying to achieve** and choose the type that best fits that need.

For more information, see the [Diátaxis documentation](https://diataxis.fr/).
